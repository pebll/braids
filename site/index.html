Features

One app. Every conversation.

braids connects to your accounts the same way the official desktop apps do, and puts every chat in one list, newest first.

Unified inbox

Every chat of every account in one list. Filter by account or open your favorites, marked with a gold ring.

Keyboard first

Jump between accounts, chats and unread messages without the mouse. Every shortcut can be changed.

Local and private

No braids server, no cloud: accounts and messages are stored only on your computer. Matrix chats stay end-to-end encrypted.

Mentions and replies

Type @ to mention someone in a group, reply, react, edit and forward, the same in every messenger.

Join groups by link

Paste a Telegram, WhatsApp or Matrix invite link and braids picks the right account.

Forward anywhere

Send a message or file from a WhatsApp group to a Signal contact, with a note where it came from.

Mentions

Tag people as you type.

Type @ in a group and pick from its members with the arrow keys. braids sends a real mention, so they get notified, whatever messenger the group is on.

Groups

Join with a link.

Paste an invite link or a room address: t.me/+…, chat.whatsapp.com/… or #room:server. braids picks the matching account and opens the group.

Keyboard

Your keys, your way.

Ctrl Space to search, Ctrl N for the next unread chat, Ctrl T for Telegram, Ctrl W for WhatsApp. Change any shortcut in the settings. They follow your keyboard layout.

Download

Get braids for Linux

Free and open source under the AGPL v3. x86_64, any recent distribution.

Recommended

Install script

Installs to your home folder (no root), adds braids to the app menu, and updates it when run again.

curl -fsSL https://pebll.github.io/braids/install.sh | sh

Remove it with curl -fsSL https://pebll.github.io/braids/install.sh | sh -s -- --uninstall

Debian and Ubuntu

A .deb package that installs to /opt/braids and pulls in the system libraries.

sudo apt install ./braids_*_amd64.deb
Download .deb

Archive

A self-contained folder: unpack anywhere and run braids/bin/braids.

tar xzf braids-linux-x86_64.tar.gz
./braids/bin/braids
Download .tar.gz

Build from source

C++, Go, Rust and Node. Telegram support compiles tdlib, which takes about an hour.

git clone https://github.com/pebll/braids
cd braids && ./make.sh deps && ./make.sh build
cd app && npm install && npm run tauri build
Build guide

Checksums and older versions

Every release lists its files with SHA-256 checksums. The install script verifies them for you.
