Features

Everything you expect from a messenger.

braids connects to your accounts the same way the official desktop apps do, so the things you use every day just work, in all four messengers.

  • Photos and videos
  • Voice messages
  • Files
  • Replies and reactions
  • @mentions
  • Edit and delete
  • Stickers and GIFs
  • Link previews
  • New groups
  • Join groups by link
  • Group info and members
  • Read receipts and typing
  • Search across all chats
  • Pinned messages
  • Notifications
  • Shared media

One inbox

Every chat of every account in one list, newest first. Favorites, mute and archive work the same everywhere.

Keyboard first

Jump between accounts, chats and unread messages without the mouse. Every shortcut can be changed.

Local and private

No braids server, no cloud: accounts and messages are stored only on your computer.

Easy setup

Link your accounts in a minute.

No new accounts, no bridges to host. braids signs in to each messenger like its own desktop app does, and your phone stays your main device.

  • Telegram: scan a QR code, or sign in with your phone number.
  • WhatsApp: scan a QR code, like WhatsApp Web.
  • Signal: scan a QR code, like Signal Desktop.
  • Matrix: your user id and password, on any homeserver.

Add as many accounts as you like, several of the same messenger too.

Forward anywhere

From any messenger, to any messenger.

Something in a Telegram group your friend on Signal should see? Forward it. Text, photos, videos and files go to any chat of any account, with a line saying where they came from.

No copying, no saving and re-uploading, no switching apps.

Calm notifications

No red dot. Just a quiet glow.

The braids icon in your panel fills with colour strand by strand: one strand for one unread chat, two for two, all three for three or more. Muted chats and group noise like "joined" don't count.

You know something is waiting, without a red badge tugging at you to look right now.

Download

Get braids for Linux

Free and open source under the AGPL v3. For x86_64 and ARM64 (aarch64), any recent distribution.

Recommended

Install script · v@VERSION@beta

Installs the latest version to your home folder (no root), adds braids to the app menu, and updates it when run again.

curl -fsSL https://pebll.github.io/braids/install.sh | sh

Remove it with curl -fsSL https://pebll.github.io/braids/install.sh | sh -s -- --uninstall

Debian and Ubuntu

A .deb package that installs to /opt/braids and pulls in the system libraries.

sudo apt install ./braids_*_amd64.deb   # or _arm64
Download .deb

Flatpak

Runs in a sandbox on any distribution with Flatpak. Updates come with each release, installed the same way.

flatpak install --user ./braids-x86_64.flatpak
flatpak run io.github.pebll.braids
Download .flatpak

Nix and NixOS

A flake with the latest release, its libraries from nixpkgs. Run it once or install it to your profile.

nix run github:pebll/braids
nix profile install github:pebll/braids
flake.nix

AppImage

One file, no installation: make it executable and start it. Needs WebKitGTK from your distribution.

chmod +x braids-x86_64.AppImage
./braids-x86_64.AppImage
Download AppImage

Archive

A self-contained folder: unpack anywhere and run braids/bin/braids.

tar xzf braids-linux-x86_64.tar.gz
./braids/bin/braids
Download .tar.gz

Build from source

C++, Go, Rust and Node. Telegram support compiles tdlib, which takes about an hour.

git clone https://github.com/pebll/braids
cd braids && ./make.sh deps && ./make.sh build
cd app && npm install && npm run tauri build
Build guide

Checksums and older versions

Every release lists its files with SHA-256 checksums. The install script verifies them for you.

All releases

Test a pull request

Every open pull request gets a test build, about 15 minutes after each push. Install it with the pull request's number, try it, and go back to the latest release with the normal command.

curl -fsSL https://pebll.github.io/braids/install.sh \
  | sh -s -- --pr 16

A branch without a pull request: --branch <name>, after running the Preview workflow on it. Test builds are not releases and can break.
